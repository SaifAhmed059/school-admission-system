# স্কুল ভর্তি সিস্টেম (School Admission System)

অনলাইন বেসরকারি স্কুল ভর্তি প্ল্যাটফর্ম — "আগে আবেদন করলে আগে পাবেন" (First Come First Served) ভিত্তিতে তাৎক্ষণিক আসন বুকিং, পেমেন্ট কনফার্মেশন ও রিয়েলটাইম সিট কাউন্টিং সিস্টেম।

---

## 🚀 টেকনোলজি স্ট্যাক (Technology Stack)

- **Backend:** C# (.NET 8 Web API)
- **Database & ORM:** PostgreSQL 16 ও Entity Framework Core 8 (Npgsql)
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Containerization:** Docker & Docker Compose
- **Testing:** xUnit, Microsoft.AspNetCore.Mvc.Testing, Vitest, React Testing Library

---

## ⚡ এক ক্লিকে Docker দিয়ে চালু করার নিয়ম (Quick Start)

মেশিনে শুধুমাত্র **Docker & Docker Compose** থাকলেই চলবে। কোনো SDK বা ডাটাবেজ আলাদা ইনস্টল করার প্রয়োজন নেই।

### ১. অ্যাপ্লিকেশন চালু করুন:
প্রজেক্টের রুট ডিরেক্টরিতে টার্মিনাল খুলে কমান্ড দিন:
```bash
docker compose up --build
```

এই কমান্ডটি স্বয়ংক্রিয়ভাবে:
1. PostgreSQL ডাটাবেজ কনটেইনার চালু করবে ও হেলথচেক নিশ্চিত করবে।
2. .NET 8 ব্যাকএন্ড বিল্ড করে ডাটাবেজ স্কিমা তৈরি করবে এবং `http://localhost:8080` পোর্টে চালু করবে।
3. React 18 ফ্রন্টএন্ড বিল্ড করে Nginx দিয়ে `http://localhost:3000` পোর্টে চালু করবে।

### ২. ব্রাউজারে অ্যাপ্লিকেশন ওপেন করুন:
- **Frontend UI:** [http://localhost:3000](http://localhost:3000)
- **Backend API:** [http://localhost:8080](http://localhost:8080)
- **Interactive Swagger API Docs:** [http://localhost:8080/swagger](http://localhost:8080/swagger)

### ৩. অ্যাপ্লিকেশন বন্ধ করা ও ডাটা সংরক্ষণ:
```bash
docker compose down
```
> **নোট:** Docker Named Volume (`pgdata`) ব্যবহার করায় `docker compose down` করার পর পুনরায় `docker compose up` দিলেও পূর্ববর্তী কোনো ডাটা হারাবে না।

## 🧪 অটোমেটেড টেস্ট চালানোর নিয়ম (Automated Tests)

### ১. ব্যাকএন্ড টেস্ট (Backend Integration & Concurrency Tests)
ব্যাকএন্ডে ৯টি অটোমেটেড টেস্ট রয়েছে, যার মধ্যে উচ্চ কনকারেন্সি টেস্ট (একসাথে ৩০টি রিকোয়েস্টে ৫টি সিট বুকিং) অন্তর্ভুক্ত:
```bash
cd backend
dotnet test
```

### ২. ফ্রন্টএন্ড টেস্ট (Frontend Unit & Component Tests)
ফ্রন্টএন্ডের ১৭-ডিজিটের ভ্যালিডেশন, এক্সপায়ার্ড কাউন্টডাউন, বাটন ডিজেবল এবং ডিজিটাল রশিদের টেস্ট যাচাই করতে:
```bash
cd frontend
npm test
```

## 🔑 মূল সুবিধাসমূহ (Key Features)

1. **কঠোর কনকারেন্সি নিরাপত্তা (Rule 1 & Bonus 1):**
   - ডাটাবেজ স্তরে `SELECT ... FOR UPDATE` রো-লেভেল লকিং ব্যবহারের মাধ্যমে নিশ্চিত করা হয়েছে যে যত হাজার রিকোয়েস্টই একসাথে আসুক বা যতগুলো ব্যাকএন্ড প্রসেসই চলুক—`held + confirmed <= totalSeats` কখনো লঙ্ঘিত হবে না।
2. **স্বয়ংক্রিয় মেয়াদোত্তীর্ণ সিট রিলিজ (Rule 2):**
   - এপিআই কল ছাড়াই মেয়াদ শেষ হওয়ার সাথে সাথে কোয়েরি লেভেলে সিট মুক্ত হয়ে যায়। ব্যাকগ্রাউন্ড ক্লিনার সার্ভিস রেকর্ড ক্লিন রাখে।
3. **আইডেমপোটেন্ট কনফার্মেশন (Rule 5):**
   - একই আবেদনে কনফার্মেশন একাধিকবার এলেও কনফার্মড সিট সংখ্যা একবারই বাড়ে।
4. **লগইনহীন নিরাপদ পরিচয় (No Login Required):**
   - পেজের উপরে শিক্ষার্থীর ১৭ অঙ্কের জন্ম নিবন্ধন নম্বর দিয়ে তাৎক্ষণিক আবেদন করা যায়। লোকালস্টোরেজে এটি সেভ থাকে।
5. **রিয়েলটাইম পোলিং ও কাউন্টডাউন টাইমার (Rule 9, 10 & 11):**
   - প্রতি ৪ সেকেন্ড পর পর রিলোড ছাড়াই আসন সংখ্যা হালনাগাদ হয়।
   - চলমান আবেদনের জন্য লাইভ টাইমার চলে এবং মেয়াদ শেষে রিলোড ছাড়াই বাটন অকার্যকর হয়ে `EXPIRED` স্ট্যাটাস দেখায়।
6. **ইউজার-ফ্রেন্ডলি বাংলা এরর হ্যান্ডলিং (Rule 12):**
   - সিট শেষ, ভুল ইনপুট বা সার্ভার অফলাইনের এরর ব্যবহারকারীর বোধগম্য ভাষায় প্রদর্শিত হয়।
7. **ভর্তি নিশ্চিতকরণ রশিদ ও প্রিন্ট সুবিধা (Admission Slip & Print):**
   - ভর্তি ফি জমা দেওয়ার পর শিক্ষার্থীর জন্য স্বয়ংক্রিয় ডিজিটাল ভর্তি রশিদ (Admission Confirmation Slip) জেনারেট হয় এবং যেকোনো সময় সরাসরি প্রিন্ট বা PDF হিসেবে সংরক্ষণ করা যায়।
8. **কন্টেইনার হেলথ চেক ও প্রোব (`GET /health`):**
   - ব্যাকএন্ড সার্ভিসের সক্রিয়তা ও ডাটাবেজ স্বাস্থ্য পর্যবেক্ষণের জন্য প্রোডাকশন-রেডি হেলথ চেক এণ্ডপয়েন্ট অন্তর্ভুক্ত।

## 📋 API Contract Summary

Base URL: `http://localhost:8080` (All JSON, `X-Student-Id` header for student endpoints)

| # | Method | Path | বিবরণ |
|---|---|---|---|
| 1 | `POST` | `/classes` | নতুন ক্লাস ও শিফট তৈরি |
| 2 | `GET` | `/classes` | সব ক্লাসের আসন হিসাবসহ তালিকা |
| 3 | `GET` | `/classes/{classId}` | একটি ক্লাসের আসন অবস্থা |
| 4 | `POST` | `/classes/{classId}/holds` | সিট সাময়িক বুকিং (Seat Hold) |
| 5 | `GET` | `/holds/{holdId}` | আবেদনের বর্তমান অবস্থা |
| 6 | `POST` | `/holds/{holdId}/confirm` | ভর্তি ফি জমা ও ভর্তি নিশ্চিতকরণ |
| 7 | `DELETE` | `/holds/{holdId}` | আবেদন বাতিল ও সিট রিলিজ |
| 8 | `GET` | `/me/holds` | এই শিক্ষার্থীর সকল আবেদন |
| 9 | `GET` | `/health` | সার্ভিস হেলথ চেক ও আপটাইম মনিটরিং |
